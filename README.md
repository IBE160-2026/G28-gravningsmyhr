# G28 Beer Game

Gruppeprosjekt i IBE160 Programmering med KI ved Høgskolen i Molde, høsten 2026.

## Status
Planlegging. Appen er ikke implementert eller publisert. Dokumentene inneholder arbeidsforslag, ikke dokumenterte testresultater eller faglærergodkjenning.

V1 planlegges som solo-spill mot regelbaserte medspillere, med lagring, grafer, sluttoppsummering og enkel læreroversikt. Flerspiller med mennesker utsettes.

## Neste utviklingssteg
S01 validerer teknisk oppstart. S02 lager en kontrollert fullkjedefasit før spillmotoren godtas. Se utviklingsoppgavene for rekkefølge og kriterier.

## Kjøring og publisering
Det finnes foreløpig ingen installasjons- eller startkommando for appen. Slike instruksjoner legges inn når de er prøvd mot faktisk kode. Planlagt publiseringsmål er Vercel. Nettadressen legges inn etter faktisk publisering.

## KI og kvalitetssikring
Planene er utarbeidet med KI-støtte på studentens bestilling. Avklaringer og faktiske resultater dokumenteres fortløpende. Ingen test eller selvstendig vurdering skal registreres som utført før den faktisk er gjennomført.
